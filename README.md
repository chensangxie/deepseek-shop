# 云间 YUNJIAN · 餐厅首页

一个**零依赖、完全离线可用**的餐厅官网首页。直接双击 `index.html` 即可打开，不需要构建、不需要联网。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 + 18 个手绘内联 SVG 插画（招牌汤面、4 道菜品、4 个环境场景、图标） |
| `styles.css` | 设计令牌 + 全部样式，共 9 个分区，含响应式与无障碍适配 |
| `script.js` | 全部交互，单个 IIFE，无第三方库 |

## 页面结构

首屏 → 跑马灯 → 招牌四味 → 今日菜单（标签页）→ 关于我们 → 店内环境（图集）→ 食客评价 → 在线订座 → 页脚

## 交互功能

- **滚动入场**：`IntersectionObserver` 驱动，同组元素错峰 90ms 出场
- **移动端抽屉导航**：汉堡按钮、点击遮罩/Esc 关闭、窗口变宽自动复位
- **滚动监听高亮**：当前所处板块的导航项自动点亮
- **菜单标签页**：鼠标点击 + 键盘 `←/→/Home/End` 完整支持，符合 ARIA tab 规范
- **营业状态**：按当前真实时间判断"营业中 / 已打烊 / 今日几点开门"，每分钟刷新
- **订座表单**：日期最小值锁定今天、手机号正则校验、字段级错误提示、成功后展示预订摘要
- **回到顶部**：滚动 640px 后出现

## 想改内容？

- **改配色**：只需要动 `styles.css` 顶部 `:root` 里的设计令牌，例如把 `--gold: #c8a24a` 换成你的品牌色，全站自动跟着变。
- **改菜品 / 菜单 / 评价**：直接在 `index.html` 里搜索对应文字修改即可，卡片会自动适应高度。
- **改营业时间**：两处需要同步——`script.js` 里的 `HOURS` 对象（用于状态判断）和 `index.html` 页脚的营业时间列表。
- **换成真实照片**：每个插画都是内联 `<svg>`。把 `<svg>…</svg>` 整段替换成 `<img src="你的图片.jpg" alt="描述">` 即可，`.dish-art` / `.gallery-item` 的容器样式不用改（图集已按裁切模式设计）。

## 兼容性与无障碍

- 支持 Chrome / Edge / Safari / Firefox 近两年版本；`100svh` 有 `100vh` 回退
- 断点：1080px / 860px / 620px
- 全站键盘可操作，焦点环可见，含"跳到主要内容"链接
- 遵循 `prefers-reduced-motion`，并提供打印样式

> 说明：页面中的店名、地址、电话、价格、评价均为示例内容，所有插画为原创 SVG，可自由替换。
